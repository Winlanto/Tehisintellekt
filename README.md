# Tehisintellekt ja masinõpe (IFI6242.DT)

## Tund 1 - minimax funktsioon, rekursioon

Esimesel tunnil oli tehtud:

- **Praktiline ülesanne (Mäng sammudega +1 ja +2):** Mängu loogika programmeerimine, kus mängijad saavad oma kordamööda teha ainult kindlaid käike (lisada väärtusele +1 või +2).
- **Rekursiooni kasutamine:** Funktsiooni loomine, mis kutsub iseennast välja, et simuleerida kõiki võimalikke tuleviku käike kuni mängu lõpuni (baasjuhuni).
- **Minimax algoritmi implementeerimine:** Algoritmi kirjutamine, mis hindab tekkinud mängupuud (game tree). See leiab hetkeseisust parima võimaliku käigu (maksimeerib oma skoori), eeldusel, et ka vastane mängib optimaalselt (minimeerib sinu skoori).
